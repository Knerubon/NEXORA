  authentication is not independently approved (`V4_PRINCIPAL_AUTHENTICATION_AVAILABLE = False`).
  Every bundle is BLOCKED; best outcome is `RECORDABLE_PENDING_REVIEW`, never TRUSTED.
- **B-M3.** No reviewed extractor entry point lets this package drive the real half without
  operator-written code; eight real-half steps stay BLOCKED (`REAL_HALF_STEPS`).
- **DEP-02.** `PROVEN_PLATFORMS = {"linux"}`: a Windows dataset cannot be TRUSTED
  (`platform_unproven:win32`). `msvcrt.locking` exclusivity on NTFS is UNVERIFIED.
- **Ordering metric.** #96 and the oracle define out-of-order differently (D6: 1 versus 2); the choice is open (DEPENDENCY-REGISTER.md).
- Windows/NTFS/MT5 readiness is **not claimed**.
